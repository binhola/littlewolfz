#### Historical Breakthrough: The November Revolution
- **1974 Discovery**: Simultaneous discovery of $J/\psi$ at BNL (p-Be collisions) and SLAC ($e^+ e^-$ collisions)
- **Key Observation**: Extremely narrow width (~ 93 keV) → 1000× longer lifetime than expected
- **Interpretation**: First evidence of **charm quark** as $c \bar c$ bound state
- **QCD Validation**: Narrow width + excited states $\psi(2S)$ proved:
  - **Asymptotic Freedom** (weak coupling at short distances)
  - **Confinement** (bound state spectrum)

#### The Cornell Potential: Modeling QCD Forces
The quark-antiquark interaction is described by:

$$V(r) = -\frac{4}{3}\frac{\alpha_S(r)}{r} + \sigma r $$

| Term            | Physics                                                                            | Parameters                                               |
| :-------------- | :--------------------------------------------------------------------------------- | :------------------------------------------------------- |
| $-4\alpha_s/3r$ | **Short-range** (perturbative)<br>One-gluon exchange<br>Analogous to QED Coulomb   | $\alpha_s$: running coupling<br>4/3 : SU(3) color factor |
| $\sigma_r$      | **Long-range** (non-perturbative)<br>Confinement via flux tube<br>Linear potential | $\sigma \approx 0.2 GeV^2$: string tension               |

**Physical Picture**: Quarks connected by "rubber band" - easy to move together, impossible to separate.

#### Charmonium Spectrum & Decay Mechanisms
**Key Concept**: **Open-charm threshold** at ~ $2m_D = 3.73 \rm \, GeV$

**Below Threshold** ($J/\psi$, $η_c$, $χ_c$ states):
- **Cannot decay to D mesons**
- **Must annihilate** via gluons
- **Suppressed widths** ($αₛ^n$ suppression)

| State               | $JᴾC$ | Decay           | Width    | Suppression    |
| :------------------ | :---- | :-------------- | :------- | :------------- |
| **$η_c$**           | 0⁻⁺   | 2 gluons        | ~32 MeV  | $αₛ²$          |
| **$J/ψ$**           | 1⁻⁻   | 3 gluons + $γ$* | 93 keV   | $αₛ³$          |
| **Above Threshold** | -     | Open charm      | ~100 MeV | No suppression |

#### **4. Why Heavy Quarkonium is Fundamental**

| Advantage                      | Scientific Value                                            |
| :----------------------------- | :---------------------------------------------------------- |
| **Simple system**              | Two-body → solvable Schrödinger equation                    |
| **Non-relativistic**           | $v/c$ ~ 0.3 (charm), 0.1 (bottom)                           |
| **Probes all scales**          | Short-distance (perturbative) + long-distance (confinement) |
| **Precision laboratory**       | Mass spectrum tests potential models, lattice QCD           |
| **Clean experimental signals** | Leptonic decays ($e⁺e⁻$, $μ⁺μ⁻$) easy to detect             |

**Production**: Vector states ($J/ψ$, $Υ$) abundantly produced via virtual photons in $e⁺e⁻$ and hadron collisions.

#### **5. Modern Frontier: Exotic States**
**The X(3872) Puzzle**:
- **Mass**: 3871.65 MeV ≈ $m_D⁰$ + $m_D̄*⁰$
- **Quantum Numbers**: 1⁺⁺ (exotic for conventional c̄c)
- **Decay**: $J/ψ$ $π⁺π⁻$, $D⁰$ $\bar D*⁰$
- **Possible Interpretations**:

| Type           | Structure                  | Evidence          |
| :------------- | :------------------------- | :---------------- |
| **Molecular**  | Loosely bound $D⁰\bar D*⁰$ | Mass at threshold |
| **Tetraquark** | Compact $c̄c$ $q q̄$       | Production rates  |
| **Hybrid**     | $c̄c$ + gluonic excitation | -                 |

**Other Exotics**: $Z_c$ (3900), $Y$ (4260), $P_c$ pentaquarks

#### **6. Heavy-Ion Physics Connection**

**Quarkonium Suppression**:
- **$J/ψ$ suppression** proposed as signature of **Quark-Gluon Plasma** (QGP)
- **Deconfinement**: Screening of color charges dissociates bound states
- **Sequential melting**: Different states dissociate at different temperatures

**Current Research**:
- LHC and RHIC studies of $J/ψ$, $Υ$ production
- Probe of QGP temperature and properties
- Regeneration effects at LHC energies

**Summary**: Heavy quarkonium provides a unique window into both perturbative and non-perturbative QCD, serving as a precision laboratory for fundamental studies and a probe of extreme matter in heavy-ion collisions.

### Experimental Methods of Spectroscopy

#### Production Reaction Types

Understanding how particles are created is crucial for spectroscopy. We classify reactions into three main types:

| Type              | Definition                                   | Example                    | Purpose                                          |
| :---------------- | :------------------------------------------- | :------------------------- | :----------------------------------------------- |
| **Inclusive**     | $A + B \to X$ <br> ($X$ not specified)             | $p + p \to J/\psi + \text{anything}$     | Study production rates <br> Total cross sections |
| **Exclusive**     | $A + B \to C + D$ <br> (all particles specified) | $\gamma + p \to J/\psi + p$            | Complete kinematics <br> Amplitude analysis      |
| **Quasi-elastic** | $A + B \to C^*$ <br> ($C^*$ decays later)            | $e + p \to e + \Delta^* \to e + p + \pi$ | Study excited states <br> Resonance properties   |

#### **3. Why Heavy Quarks are Ideal for Spectroscopy**

| Property            | Advantage for Spectroscopy                                            |
| :------------------ | :-------------------------------------------------------------------- |
| **Large Mass**      | Non-relativistic dynamics <br> De Broglie wavelength < hadron size    |
| **Identifiable**    | Clear experimental signatures <br> Unique decay patterns              |
| **Discrete Levels** | Rich spectrum of excited states <br> Clean theoretical interpretation |

**Requirements**: Large statistics + excellent detector resolution

#### **4. LHCb: A Precision Spectroscopy Machine**

##### **4.1 Detector Design**
LHCb is optimized for heavy-flavor physics with forward geometry:

Beam Pipe → Vertex Detector → Tracker → Magnet → PID → Calorimeters → Muon Chambers

**Key Components**:
- **Vertex Detector**: Precise impact parameter measurement
- **Magnet**: Momentum measurement via curvature
- **Particle ID (RICH)**: Excellent $π/K/p$ separation
- **Forward Acceptance**: Captures most $b$-hadrons

##### **4.2 LHCb's Spectroscopy Advantages**

| Feature                     | Spectroscopy Benefit                             |
| :-------------------------- | :----------------------------------------------- |
| **High Statistics**         | Rare decays and exotic states                    |
| **Excellent Resolution**    | Clean mass peaks <br> Narrow width measurements  |
| **Particle Identification** | Background suppression <br> Pure final states    |
| **Forward Boost**           | Long lifetimes measurable <br> Vertex separation |
| **Software Trigger**        | Flexible selection of interesting events         |

---

#### **5. Modern Analysis Techniques**

##### **5.1 Amplitude Analysis**
- **Purpose**: Extract quantum numbers ($JᴾC$) from angular distributions
- **Method**: Decompose data into partial waves
- **Example**: Jülich-Bonn collaboration analysis of light resonances
##### **5.2 Key Discoveries at LHCb**
- **Pentaquarks**: First observation of 5-quark states
- **Exotic Charmonium**: $X$ (3872), $Z$ (4430) and similar states
- **Doubly-Charmed Baryons**: First observation of $Ξ^{₊₊} (ccu)$

---

#### **6. The Spectroscopy Pipeline**

Collision → Reconstruction → Particle ID → Mass Reconstruction → Amplitude Analysis → Quantum Numbers

**Modern Success Factors**:
1. **High luminosity** for statistical precision
2. **Advanced detectors** for resolution
3. **Sophisticated triggers** for event selection
4. **Complex analysis** for quantum number determination

This experimental framework has transformed hadron spectroscopy from discovery of basic constituents to precision studies of exotic matter forms.
